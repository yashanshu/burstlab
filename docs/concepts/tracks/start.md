# Start here

**Goal:** What BurstLab is, what a lesson needs, and where to begin.

These are timed self-tests, not articles. Each one hands you a problem before
the explanation, so reading it straight through gets you nothing.

**Running one alone.** Write your answer down *before* opening any
`Success criteria` block — those state explicit criteria, so you can mark
yourself against them. Checkpoint 5 wants 250–350 words covering the five
evidence prompts listed at the top; write it, then paste it and those prompts
into any capable LLM chat and ask it to score you against the
`Evaluator use only` block. Four of five passes. Opening that block early
costs you the only thing the lesson was measuring.

These were written for a chat session running the `concept-speedrun` skill,
which adds the prerequisite gate and a repair loop. Everything else works
solo. The minute figures are budgets, not deadlines.

**What is readable.** [Lessons](/) lists everything published, in order. The
[nine-concept sequence](/burstlab/) is the whole plan and doubles as the
author's progress log — a row with a lesson link is written, a row with a dash
is not. The later concepts build real AWS infrastructure and spend real money;
none of those are published yet.
